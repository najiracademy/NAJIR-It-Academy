NAJIR It Academy — Website Starter
==================================

Included files:
- index.html: Main bilingual website content
- style.css: Responsive design and visual styling
- script.js: Bengali/English toggle and mobile menu
- favicon.svg: Simple browser icon

Preview:
Open index.html in Chrome or another web browser.

Free hosting:
You can publish this static website using GitHub Pages or Netlify.
No server/database is included in this starter site.

Before publishing:
1. Replace the placeholder contact text in index.html with your verified phone number, address, and email.
2. Check course details and adjust them to match what you actually offer.
3. If using GitHub Pages, upload all four website files into the repository root.
4. Test both Bengali and English views on mobile and desktop.
